# Ảnh hưởng của tiện ích xung quanh lên giá bất động sản TP.HCM

Dự án phân tích mối quan hệ giữa các tiện ích xung quanh và giá bất động sản tại TP.HCM.
Giai đoạn hiện tại tập trung thu thập dữ liệu mẫu (1.000 - 2.000 tin đăng), lưu trữ và thực hiện phân tích khám phá dữ liệu (EDA) cơ bản.
Dữ liệu được thu thập và xử lý phục vụ mục đích học tập và nghiên cứu phân tích.

## Thiết lập môi trường

### Windows (PowerShell, tại thư mục gốc dự án)
```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

### macOS/Linux (tại thư mục gốc dự án)
```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
```
